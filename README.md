# TP — Architectures PyTorch sur MNIST

Comparaison de cinq architectures sur MNIST, entraînées et évaluées sur une NVIDIA RTX 3050 Laptop GPU.

| Modèle | Accuracy test |
|---|---:|
| CNN | 99,07 % |
| Faster R-CNN | 98,67 % |
| VGG16 | 96,87 % |
| AlexNet | 94,62 % |
| Vision Transformer | 97,16 % |

Consulter le **[rapport complet en français](TP_PyTorch/README.md)** pour le protocole, les résultats, les figures, les limites de comparaison et les instructions d'exécution.

Le dossier [TP_PyTorch](TP_PyTorch/) contient les cinq scripts indépendants à cellules `# %%`, les dépendances, les métriques JSON et les journaux d'exécution. Les datasets, poids téléchargés et environnements locaux sont exclus du dépôt.
